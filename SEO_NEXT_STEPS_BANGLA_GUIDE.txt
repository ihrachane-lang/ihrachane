PART 1 — Google Search Console setup ও sitemap submission
=========================================================

যা লাগবে
----------
- Website domain-এর DNS বা hosting access
- একটি company-controlled Google account
- Live website: https://www.ihrachane.com
- Live sitemap: https://www.ihrachane.com/sitemap.xml

Step 1: Property তৈরি করুন
--------------------------
1. ব্রাউজারে https://search.google.com/search-console/ খুলুন।
2. “Add property” চাপুন।
3. “Domain” option নির্বাচন করুন।
4. এখানে লিখুন: ihrchane.com নয়; website-এর আসল domain অনুযায়ী `ihrachane.com` লিখুন।
5. Google একটি DNS TXT record দেবে।
6. Domain যেখানে manage করা হয় (Cloudflare, GoDaddy, Namecheap, hosting panel ইত্যাদি)
   সেখানে DNS > Add record এ যান।
7. Type = TXT, Name/Host = Google-এর দেওয়া value, Value = Google-এর দেওয়া token দিন।
8. Save করুন। DNS update কয়েক মিনিট থেকে 24 ঘণ্টা লাগতে পারে।
9. Search Console-এ ফিরে “Verify” চাপুন।
#######----DONE-------###########

Step 2: Sitemap submit করুন
---------------------------
1. বাম menu থেকে “Sitemaps” নির্বাচন করুন।
2. “Add a new sitemap” box-এ লিখুন: `sitemap.xml`
3. Submit চাপুন।
4. Status “Success” হওয়া পর্যন্ত অপেক্ষা করুন।
5. যদি “Couldn't fetch” আসে:
   - Incognito browser-এ https://www.ihrachane.com/sitemap.xml খুলে দেখুন।
   - https://www.ihrachane.com/robots.txt খুলে sitemap URL আছে কি না দেখুন।
   - 200 status code, HTTPS certificate এবং deployment ঠিক আছে কি না developer-কে জানান।

Step 3: গুরুত্বপূর্ণ URL inspection করুন
---------------------------------------
Search Console > URL Inspection-এ প্রতিটি URL paste করুন:

- https://www.ihrachane.com/
- https://www.ihrachane.com/tr
- https://www.ihrachane.com/services/sourcing
- https://www.ihrachane.com/tr/cin-tedarik
- https://www.ihrachane.com/services/quality-inspection
- https://www.ihrachane.com/tr/cin-fabrika-denetimi
- https://www.ihrachane.com/services/china-to-turkey-freight
- https://www.ihrachane.com/tr/cinden-turkiyeye-lojistik

প্রতিটির জন্য:
1. “Test Live URL” চালান।
2. “URL is available to Google” অথবা indexable status নিশ্চিত করুন।
3. নতুন/পরিবর্তিত page হলে “Request Indexing” একবার চাপুন।
4. বারবার request করবেন না; meaningful change ছাড়া এটি দরকার নেই।

Step 4: প্রতি সপ্তাহে Search Console-এ যা দেখবেন
------------------------------------------------
1. Pages report: “Not indexed” URL-এ 404, redirect, duplicate বা noindex আছে কি না।
2. Sitemaps report: submitted vs discovered URL count।
3. Performance report:
   - Country filter: Turkey, তারপর all countries
   - Query filter: sourcing, supplier, China, inspection, logistics এবং Turkish variants
   - Page filter: /tr এবং /services/ URLs
4. Core Web Vitals report: mobile আগে দেখুন।
5. Manual Actions এবং Security Issues: সবসময় zero হওয়া দরকার।


PART 2 — Bing Webmaster Tools setup || letter
===================================

1. https://www.bing.com/webmasters/ খুলুন।
2. Company Microsoft account দিয়ে sign in করুন।
3. “Add a Site” নির্বাচন করুন।
4. Search Console property import করার option থাকলে সেটি ব্যবহার করুন; সবচেয়ে সহজ।
5. না থাকলে domain verify করুন DNS TXT record দিয়ে।
6. Sitemap হিসেবে `https://www.ihrachane.com/sitemap.xml` submit করুন।
7. Bing Webmaster-এর “Site Explorer”, “Indexing” এবং “SEO Reports” সপ্তাহে একবার দেখুন।

Verification checklist:
- Domain verified
- Sitemap accepted
- গুরুত্বপূর্ণ English/Turkish URLs discovered

PART 3 — GA4 analytics ও conversion tracking
=============================================

যা লাগবে
----------
- Company Google account
- Website deployment access
- Consent/privacy policy review করার দায়িত্বশীল ব্যক্তি

Step 1: GA4 property তৈরি করুন
------------------------------
1. https://analytics.google.com/ খুলুন।
2. Admin > Create > Property নির্বাচন করুন।
3. Name: `IHRACHANE Website` দিন।
4. Time zone এবং currency business অনুযায়ী সেট করুন।
5. Web data stream তৈরি করে website URL দিন।
6. Measurement ID কপি করুন; format হবে `G-XXXXXXXXXX`।

Step 2: Developer-কে implementation instruction দিন
---------------------------------------------------
Developer-কে বলুন:
- Google Tag Manager ব্যবহার করে GA4 install করতে, অথবা Next.js-এর official Script
  integration দিয়ে GA4 tag যোগ করতে।
- EU/UK/Turkey visitors থাকলে cookie consent-এর আগে non-essential analytics চালু না করতে।
- Production এবং staging environment আলাদা রাখতে।

Step 3: যে conversion event track করবেন
----------------------------------------
প্রতিটি event-এর নাম এবং trigger লিখিতভাবে approve করুন:

- generate_lead: sourcing/contact form successfully submit
- form_start: user form-এ প্রথম input দেয়
- whatsapp_click: WhatsApp link/button click
- phone_click: tel: link click
- email_click: mailto: link click
- quote_request: “Request a Quote” CTA click বা submit
- language_switch: English/Turkish language page navigation

Step 4: GA4-এ conversion mark করুন
-----------------------------------
1. Events report-এ event আসছে কি না দেখুন।
2. Admin > Key events-এ `generate_lead` এবং `quote_request` key event হিসেবে mark করুন।
3. প্রতি মাসে এই report তৈরি করুন:
   - Organic Search sessions
   - Organic leads
   - Lead conversion rate
   - English vs Turkish landing page leads
   - Qualified lead এবং closed business value (CRM থেকে)


PART 4 — Turkish technical SEO যাচাই
====================================

বর্তমান Turkish priority URLs
-----------------------------
- /tr
- /tr/cin-tedarik
- /tr/cin-fabrika-denetimi
- /tr/cinden-turkiyeye-lojistik

Deployment-এর পরে verification
-------------------------------
1. প্রতিটি URL browser-এ খুলুন; page 200 return করছে নিশ্চিত করুন।
2. Page source-এ নিচের alternate links আছে কি না দেখুন:
   - hreflang="en"
   - hreflang="tr"
   - hreflang="x-default"
3. English page Turkish page-কে এবং Turkish page English page-কে reciprocal ভাবে reference
   করছে নিশ্চিত করুন।
4. Turkish copy একজন native Turkish business writer দিয়ে proofread করান।
5. Turkish page-এ English page-এর exact duplicate publish করবেন না। Turkish market, Turkey
   import process, route, currency/requirements এবং Turkish buyer concern অনুযায়ী content
   আলাদা করুন।
6. `html lang="tr"` architecture শক্ত করার কাজ developer-এর জন্য: route-group ভিত্তিক
   separate Turkish root layout বা locale-aware document layout ব্যবহার করতে হবে। এটি করার
   আগে staging-এ test করুন যাতে existing English SSG/metadata ভেঙে না যায়।


PART 5 — Real case study তৈরি
=============================

কেন দরকার
----------
Case study generic claim-এর চেয়ে অনেক বেশি trust তৈরি করে। এটি sales, SEO এবং backlink
outreach—তিন জায়গায় ব্যবহার হবে। শুধুমাত্র সত্য, client-approved information ব্যবহার করুন।

প্রথম 3টি case study বাছাইয়ের নিয়ম
----------------------------------
1. ভিন্ন service দেখান: sourcing, quality inspection, logistics।
2. সম্ভব হলে একটি Turkey-related route বা Turkish customer problem অন্তর্ভুক্ত করুন।
3. Client-এর written permission নিন। নাম প্রকাশ করা না গেলে industry/region anonymize করুন।
4. ফলাফল প্রমাণ করা যায় এমন case নিন।

Case study template
-------------------
প্রতিটি article-এ এই sections থাকবে:

1. Title
   Example: “How IHRACHANE helped a Turkish retailer verify suppliers before first order”
2. Client profile
   Industry, country, order type; confidential data বাদ দিন।
3. Challenge
   Client-এর আসল problem কী ছিল? যেমন supplier reliability, quality risk, consolidation।
4. Scope
   IHRACHANE কী কাজ করেছে? factory shortlist, audit, sampling, QC, warehouse, freight।
5. Process
   3-6টি বাস্তব step লিখুন। ছবি বা redacted report excerpt যোগ করা যায়।
6. Outcome
   Factual metrics দিন: inspected factories, rejected defects, lead-time visibility,
   consolidated shipments, repeat orders ইত্যাদি। অনুমান বা বানানো percentage দেবেন না।
7. Client quote
   নাম/role/approval থাকলে সবচেয়ে শক্তিশালী।
8. CTA
   Related quote-request page-এ link দিন।

প্রকাশ পরিকল্পনা
---------------
- English master article: /resources/[slug]
- Turkish equivalent: /tr/rehber/[slug]
- একই article word-for-word translate না করে Turkish buyer-এর জন্য practical notes যোগ করুন।
- প্রতি case study থেকে relevant service page-এ internal link দিন।

Step 1: Test URLs
-----------------
https://pagespeed.web.dev/ খুলে mobile এবং desktop—দুই mode-এ test করুন:

Step 2: ফলাফল spreadsheet-এ লিখুন

URL | device | Performance | LCP | INP | CLS | top issue | owner | due date

Target:
- LCP: 2.5 seconds বা কম
- INP: 200 ms বা কম
- CLS: 0.1 বা কম

Step 3: Common fixes (developer checklist)
------------------------------------------
1. Hero image-এর actual display size অনুযায়ী Cloudinary transformation ব্যবহার করুন।
2. Above-the-fold image priority দিন, নিচের images lazy-load করুন।
3. `next/image`-এ suitable `sizes` দিন; huge image mobile-এ পাঠাবেন না।
4. PNG/JPG সম্ভব হলে WebP বা AVIF-এ serve করুন।
5. Unused JavaScript, large carousel এবং third-party script কমান।
6. Image width/height reserve করুন যাতে CLS না হয়।
7. Font loading ও external widgets পরীক্ষা করুন।
8. Fix করার পরে একই URL আবার PageSpeed Insights-এ test করুন।
9. Search Console Core Web Vitals field data update হতে 28 দিন পর্যন্ত সময় লাগতে পারে।


PART 10 — Dynamic category/subcategory copy rewrite workflow
=============================================================

কেন দরকার
----------
বর্তমান dynamic templates অনেক জায়গায় একই generic copy ব্যবহার করে। প্রতিটি indexable
category/subcategory page-এর নিজস্ব commercial intent ও unique value দরকার।

Step 1: সব URL export করুন
--------------------------
Sitemap এবং CMS থেকে spreadsheet বানান:

URL | page type | primary keyword | language | current title | current H1 |
unique content? | action | owner | status

Step 2: Quality decision নিন
----------------------------
প্রতিটি page-এর জন্য কেবল একটি action নির্বাচন করুন:

- Keep + rewrite: valuable/real service/category
- Merge + 301: একই intent-এর duplicate page
- Noindex: thin, temporary, internal বা no-search-value page
- Delete + 410/404: permanently invalid/test page

Step 3: English page writing template
-------------------------------------
1. SEO title: primary intent + benefit, প্রায় 50-60 character
2. Meta description: clear offer + audience + CTA, প্রায় 140-160 character
3. One H1: page-এর exact topic
4. 2-4 unique introductory paragraphs
5. Specific sourcing/geography/process/quality/lead-time information
6. Relevant FAQ
7. 3-5 contextual internal links
8. Quote CTA

Step 4: Turkish equivalent writing template
-------------------------------------------
1. Turkish primary intent দিয়ে unique title/H1 লিখুন।
2. Turkish buyer-এর context যোগ করুন: China-to-Turkey route, required documents, shipping
   decision, supplier risk ইত্যাদি—শুধু translate করবেন না।
3. Turkish page-এ self-canonical এবং reciprocal hreflang থাকবে।
4. Native Turkish reviewer দিয়ে approve করান।

Step 5: প্রতি সপ্তাহের rewrite target
-------------------------------------
- প্রথমে revenue potential সবচেয়ে বেশি 5টি English page rewrite করুন।
- পরে তাদের Turkish equivalent তৈরি করুন।
- সবশেষে low-value pages merge/noindex করুন।
- Publish-এর 4-8 সপ্তাহ পরে Search Console-এ impressions, CTR, query এবং lead compare করুন।
